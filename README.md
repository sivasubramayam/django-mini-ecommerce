# Django Mini E-Commerce

A simple e-commerce web application built using Django and MySQL.

## Features

- User Registration & Login
- Product Management
- Product Categories
- Product Search
- Shopping Cart
- Remove from Cart
- User Profile
- Order Placement
- Django Admin Panel
- Image Upload
- MySQL Database

## Tech Stack

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap

## Installation

```bash
git clone https://github.com/sivasubramayam/django-mini-ecommerce.git
cd django-mini-ecommerce

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
